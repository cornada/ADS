# [KT11] Related work coverage + must-cite integration (no hallucinated references)

**Generated:** 2026-01-15  
**Owner:** Paper lead (human) + Claude Code (assist for extraction/formatting)

## Goal
Make the related-work section **reviewer-proof** by producing:
1) a structured related-work matrix (what each close paper does / dataset / eval / what we add),
2) a must-cite bib integration workflow (only verified entries),
3) a novelty map: "them vs us" bullets (technical, not marketing).

## Why (reviewer risk addressed)
After AAMAS issues, this is critical:
- IJCAI reviewers will punish missing/incorrect citations.
- Any unverified reference is a potential paper-killer.

## Inputs
- Your existing `paper/references.bib`
- Must-cite bib sets you already prepared (IJCAI core + outside core)
- KT2.0 tools: `tools/verify_bib.py` (fail on unverified)

## Deliverables
### A) Related work matrix
- `docs/related_work/RELATED_WORK_MATRIX.csv`

Minimum columns:
- paper_id
- citation_key
- venue_year
- track (HAI / Demo / Main / etc)
- setting (education / agentic tutoring / recommender / MORL / fairness / etc)
- multi-agent (Y/N)
- multi-objective (Y/N)
- human-in-the-loop (Y/N)
- data (real/synthetic; what kind)
- evaluation (user study / offline metrics / both)
- key novelty vs ADS (1–2 bullets)
- overlap risk (low/med/high)
- cite_status (verified / needs_check)

### B) Novelty map doc
- `docs/related_work/NOVELTY_MAP.md`
Sections:
- closest neighbors (IJCAI-25-ish style systems)
- MORL / normative constraints / fairness stability
- contestable AI / recourse / what-if explanations
- what ADS uniquely contributes (vector-valued evaluation + Pareto + contestability + stability)

### C) Bib integration (verified only)
- Update `paper/references.bib`:
  - import must-cite entries you truly need
  - remove duplicates
  - ensure every entry passes verification

### D) Verification report
- `reports/reference_audit.json` (or similar)
Generated by:
- `python tools/verify_bib.py paper/references.bib --report reports/reference_audit.json --fail_on_unverified`

## Acceptance criteria
- [ ] `python tools/verify_bib.py ... --fail_on_unverified` passes
- [ ] Matrix has >= 25 rows (or all close/needed works), with verified cite_status
- [ ] Novelty map has a 1-paragraph "positioning" draft that is consistent with the matrix
- [ ] No invented DOIs / venues / page numbers
