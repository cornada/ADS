# Reproducibility Checklist (IJCAI-friendly)

## Environment
- [ ] Pin dependency versions (lockfile or container tag)
- [ ] Record python version + OS + GPU/CPU info (optional)

## Data provenance
- [ ] Store `source_url`, `timestamp`, `raw_text_hash` for every artifact
- [ ] Keep a snapshot of all raw texts used in experiments (or deterministic re-download script)
- [ ] For each experiment, write `dataset_hashes.json`

## Model provenance
- [ ] Record `embedding.model_id` (and model name + revision if from HF)
- [ ] Cache embeddings + store cache metadata

## Determinism
- [ ] Set seeds in numpy/random/torch (if used)
- [ ] Record seed in each run folder

## Experiments
- [ ] Each run writes `config.yaml` (resolved), `git_commit`, `seed`
- [ ] Outputs stored in `experiments/reports/<run_id>/`
- [ ] Figures and tables generated by script, not manually

## Baselines
- [ ] Baseline code included as submodule (permissive license) or re-implemented
- [ ] Record commit hash + license in THIRD_PARTY_NOTICES.md

## Paper artifacts
- [ ] `paper_tables/` contains CSV used in LaTeX tables
- [ ] `figures/` contains final PNG/PDF used in paper
