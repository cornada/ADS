%% Abstract
\begin{abstract}
We release a cross-national educational benchmark for multi-objective pathway evaluation, spanning {\NumCourses} courses from {\NumUniversities} universities across {\NumCountries} countries (USA, Sweden, UK), {\NumOccupations} O*NET occupations, and {\NumAttributeRecords} structured skill/task links---{\HeadlineRecords}+ processed records in total, all from public sources with full provenance.
No existing benchmark combines multi-stakeholder educational artifacts at this scale with standardized evaluation tasks. We define three benchmark tasks (multi-stakeholder ranking, trade-off discovery, robust recommendation) with formalism-independent evaluation metrics, and provide Agent-Didactic Spaces (\ADS) with Multi-Agent Pareto Evaluation (\MAPE) as a reference baseline. \MAPE embeds educational options and stakeholder targets into a shared space, computes per-stakeholder similarity scores, enforces a tunable dominance threshold~$\tau$, and returns a feasible Pareto set.
At default $\tau{=}0.25$, \MAPE returns the complete feasible Pareto set ({\MainParetoSize} options), surfacing trade-offs invisible to standard scalarization. Each university contributes unique Pareto-optimal courses with complementary objective profiles, and all {\NumUnisContributing}/{\NumUniversities} institutions are represented on the frontier. We audit robustness via encoder ablation, mission-corpus expansion, seed stability, and market drift across O*NET releases (2022--2025), observing a stable robust core under perturbation but substantial sensitivity to encoder choice.
\end{abstract}

\section{Introduction}

Educational planning systems---from course recommenders to career-alignment tools---increasingly shape curriculum decisions~\cite{dasilva2022slrERS,aucancela2023ersslr}. They guide learners toward \emph{what to learn next} and, indirectly, influence which modules educators choose to create. Yet evaluating these choices requires balancing multiple objectives: learner preferences, institutional mission, and labor-market relevance each define legitimate---and sometimes conflicting---criteria for what counts as a good pathway~\cite{abdollahpouri2020multistakeholder}.

Despite the multi-objective nature of the problem, no existing benchmark combines educational artifacts from multiple institutions and countries with labor-market taxonomies and standardized multi-stakeholder evaluation tasks. Course recommendation datasets typically cover a single university~\cite{morsy2019course2vec}; labor-market benchmarks focus on job matching~\cite{giabelli2021skills2job}; and multi-objective optimization benchmarks rarely use real educational data. This gap means researchers lack a common testbed for comparing methods that must balance heterogeneous stakeholder objectives at scale.

We address this gap with three contributions. First, we release \emph{Agent-Didactic Spaces} (\ADS), an open cross-national benchmark combining university course catalogs, O*NET occupations, and structured skill/task links (details in Section~\ref{subsec:data}). Second, we define a benchmark protocol with three evaluation tasks and standardized metrics, so that any method---embedding-based, LLM-based, or otherwise---can be evaluated on the same data. Third, we provide \emph{Multi-Agent Pareto Evaluation} (\MAPE) as a reference baseline: it embeds educational artifacts into a shared space where each stakeholder is a transparent evaluation perspective defined by (i) a target corpus, (ii) an auditable \emph{lens}, and (iii) a tunable dominance threshold $\tau$ that filters options with extreme stakeholder imbalance.

\paragraph{What this paper is not.}
We do \emph{not} present an LLM tutor, and we do not claim causal improvements in learning outcomes. We focus on a \emph{benchmark and evaluation protocol} for pathway options using public artifacts and explicit objectives.

\paragraph{Contributions.}
\begin{itemize}
  \item \textit{Cross-national educational benchmark.} An open dataset spanning {\NumUniversities} universities across {\NumCountries} countries with O*NET occupations and structured skill/task links---all publicly sourced (Section~\ref{subsec:data}).
  \item \textit{Benchmark protocol with three evaluation tasks.} Multi-stakeholder ranking, trade-off discovery, and robust recommendation tasks with standardized metrics and JSON I/O, enabling method comparison without framework lock-in.
  \item \textit{\MAPE reference baseline.} A feasible Pareto evaluation method with a tunable dominance threshold ($\tau$) and retrieval-grounded explanations.
  \item \textit{Comprehensive evaluation.} Robustness audits (encoder ablation, market drift across O*NET 2022--2025, seed stability), cross-national analysis revealing complementary trade-off profiles, and preliminary practitioner feedback ($n{=}13$).
\end{itemize}

\section{Related Work and Positioning}
\label{sec:related}

\ADS/\MAPE sits at the intersection of four research threads: (i) educational recommenders and pathway planning, (ii) mapping education artifacts to labor-market needs, (iii) multi-objective optimization with normative constraints, and (iv) multi-stakeholder evaluation and transparency.

\subsection{Educational Pathway Recommendation}
Educational recommender systems recommend learning resources, courses, or sequences using learner profiles and structured constraints such as prerequisites. Recent surveys emphasize the diversity of objectives and evaluation practices in this space, and note that many deployed systems still compress evaluation into a scalar proxy~\cite{dasilva2022slrERS,aucancela2023ersslr}. Rigorous evaluation methodology remains an active concern in the broader recommendation community~\cite{rendle2019kddcup}.
Learning-path recommendation often relies on structured knowledge representations such as knowledge graphs~\cite{shi2020}.
Course recommendation also appears in mainstream AI venues: IJCAI work explores graph- and reinforcement-learning based formulations~\cite{hhcor2024,dfrp2024}.
Representation-learning approaches such as Course2Vec learn course embeddings from enrolment data~\cite{morsy2019course2vec,jiang2020multifactorCourse2vec,xu2023courseEmbeddings}.
LLM-based educational assistants target tutoring, feedback, and assessment~\cite{coderagent2025,collabAgents2025,llmGrading2025,handByHand2025,livepoem2025}---orthogonal to multi-objective evaluation.

\subsection{Skills and Labor-Market Alignment}
Mapping educational content to labor-market needs underpins career-oriented advising. Prior work embeds job offers, skills, and candidates for matching~\cite{giabelli2021skills2job,kara2022skillEmbeddings,leon2024transversalSkills,shi2020job2skills}; LLM-augmented knowledge graphs extend this to open-world settings~\cite{zhang2024recsysbench}. Career-path modelling predicts job mobility from hierarchical trajectory features~\cite{meng2019career}, and recent work addresses preference drift in job recommendation~\cite{han2024bistro}. \textbf{ADS differs:} we treat market alignment as \emph{one} objective among many.

\subsection{Multi-Objective Optimization}
Pareto optimality and scalarization are standard for preserving trade-offs~\cite{roijers2013survey_mosdm,deb2002nsga2}; a recent KDD tutorial surveys multi-objective formulations for recommendation~\cite{zheng2021multiobjective}. Recent work adds normative constraints (``restraining bolts'')~\cite{monb2025,restrainingBolts2025} and equity objectives~\cite{equityMAMORL2025}. \textbf{ADS differs:} we use Pareto as an \emph{evaluation layer} with an auditable feasibility constraint.

\subsection{Multi-Stakeholder Evaluation and Transparency}
Multi-stakeholder recommender evaluation argues quality cannot be assessed from one perspective~\cite{abdollahpouri2020multistakeholder,burke2025mseval,ge2024trustworthyRS}.
Contestable AI emphasizes that affected parties should be able to inspect and challenge decisions~\cite{aler2020contestable,alfrink2023contestable,dignum2025contesting}.
Explainability~\cite{zhang2020explainableRS} and counterfactual recourse~\cite{wachter2017counterfactual,ustun2019recourse,robustx2025} support this.
Fairness constraints matter when recommendations affect access~\cite{ekstrand2019fairness,dwork2012fairness,hardt2016equality,fairRankAgg2025,fairdas2024}; algorithmic decision-making under fairness costs formalizes the trade-off between predictive accuracy and equity~\cite{corbettdavies2017cost}. Recent work operationalizes fairness in recommendation ranking through pairwise comparisons~\cite{beutel2019fairness} and as a fair-division problem in ranked outputs~\cite{saito2022fair}.
\textbf{ADS differs:} we make objectives explicit look-up objects and return Pareto sets with retrieval-grounded explanations.

\section{Problem Setting}
\label{sec:setting}

\paragraph{Options and pathways.}
Let $\mathcal{X}$ be a set of educational options (courses, modules, projects). A \emph{pathway} is a sequence $\pi=(x_1,\dots,x_T)$ subject to feasibility constraints. In this paper we focus on \emph{option-level} evaluation (length-$1$ pathways).

\paragraph{Stakeholder perspectives.}
We consider a finite set of stakeholders $\mathcal{A}$ (e.g., learner, institution, labor market, mission). In \ADS, each stakeholder is represented as an evaluation perspective parameterized by a lens and a target corpus.

\paragraph{Goal.}
Given $\mathcal{X}$, the system returns (i) stakeholder-specific scores, (ii) the feasible Pareto set, and (iii) stakeholder-typed explanations that support informed comparison of trade-offs.


\section{\MAPE Reference Baseline}
\label{sec:method}

We provide \MAPE as a reference baseline; any method producing the required JSON output can be evaluated on the benchmark (Section~\ref{sec:benchmark-protocol}). Full formalism appears in Appendix~\ref{sec:supp-method-details}.

\paragraph{Overview.}
\MAPE embeds text artifacts (courses, job descriptions, mission statements) into a shared space via a sentence encoder $r:\mathcal{T}\to\mathbb{R}^d$, then computes per-stakeholder similarity scores via cosine similarity with auditable \emph{lenses} (identity, diagonal, or learned reweightings). Raw scores are z-score calibrated across stakeholders to enable fair comparison.

\paragraph{Dominance threshold.}
\label{subsec:constraint}
To filter options where one stakeholder objective dominates others beyond a threshold, we define a balanced dominance gap $g(x) = \max_{a,b}(s_a(x) - s_b(x))$ and retain options where $g(x) \le \tau$. The feasible Pareto set is:
\begin{equation}
  \mathcal{P}_\tau = \big\{x\in\mathcal{X}_\tau : \nexists y\in\mathcal{X}_\tau \text{ s.t. } \mathbf{s}(y)\succ \mathbf{s}(x)\big\}.
\end{equation}
Tightening $\tau$ prevents single-objective dominance; relaxing it permits stronger alignment with any individual objective. For each $x\in\mathcal{P}_\tau$, \MAPE returns stakeholder scores, the dominance gap, and retrieval-grounded explanations (nearest target artifacts per stakeholder).


\section{Benchmark Protocol}
\label{sec:benchmark-protocol}

To ensure the benchmark admits methods beyond \MAPE, we define three formalism-independent tasks with standardized JSON I/O. Any method---embedding-based, feature-engineered, or LLM-based---can produce a conforming submission without importing ADS code.

\paragraph{Task~A: Multi-Stakeholder Course Ranking.}
\textit{Input:} Course text corpus, stakeholder target corpora.
\textit{Output:} Ordered list of course IDs with optional score vectors.
\textit{Metrics:} Coverage, diversity, objective balance (Shannon entropy), Pareto alignment (precision/recall/F1 against reference front).

\paragraph{Task~B: Stakeholder Trade-off Discovery.}
\textit{Input:} Same as Task~A.
\textit{Output:} Set of course IDs representing distinct trade-offs.
\textit{Metrics:} Hypervolume (HV, $\mathbf{r}{=}\mathbf{0}$), spacing, Pareto precision, dominance resistance.

\paragraph{Task~C: Robust Recommendation.}
\textit{Input:} Same as Task~A plus perturbation protocol.
\textit{Output:} Primary submission plus ${\geq}2$ perturbation-run submissions.
\textit{Metrics:} Bootstrap Jaccard, HV retention, core stable fraction.

\paragraph{Evaluation and splits.}
A self-contained script (\texttt{benchmark\_eval.py}, NumPy + stdlib only) evaluates any submission. Development split: 3 US universities (${\approx}10{,}400$ courses); evaluation split: all {\NumUniversities} universities.

\paragraph{External baseline validation.}
TF-IDF and BM25 baselines (zero ADS imports) confirm the protocol discriminates meaningfully: TF-IDF achieves HV$=$0.296 with Pareto precision 0.52 vs.\ random HV$=$0.080, precision 0.02 (Table~\ref{tab:external-baselines} in the appendix).

\paragraph{Encoder-consensus reference front.}
To address encoder sensitivity (cross-encoder Jaccard as low as 0.021), we compute Pareto fronts under three encoders (MiniLM, MPNet, BGE-small) and define a \emph{majority-consensus front}: courses Pareto-optimal under $\geq$2/3 encoders (31 courses, mean per-encoder Jaccard 0.13). We recommend this as the benchmark's default reference set (Appendix~\ref{sec:supp-encoder-consensus}).


\section{Practitioner Feedback}
\label{sec:collab}

We designed \ADS/\MAPE in conversation with practice. Formative interviews with three senior stakeholders at an \IndustryPartner{} converged on three needs: (i) make market--pedagogy tensions explicit, (ii) prefer a Pareto set over a single ranked list (a \emph{decision map}), and (iii) treat $\tau$ as a configurable guardrail against market-dominant drift.

A preliminary pilot ($n{=}13$; 7 course developers, 6 instructional designers) provided directional evidence: Trade-off Transparency scored 4.85/5, Usefulness vs.\ ranked lists 4.38/5, Clarity 4.23/5. Cognitive Load (3.38/5) fell below neutral, confirming the Pareto presentation increases perceived effort---a limitation of the current design. We do not claim \ADS/\MAPE reduces effort; it shifts effort from searching to interpreting trade-offs. Full pilot details, rating distributions, and qualitative quotes appear in Appendix~\ref{sec:supp-stakeholder}.


\section{Experiments}
\label{sec:experiments}

The experiments below ask: when we apply \ADS/\MAPE to public educational and labor-market artifacts at scale, does it expose a non-trivial, stable trade-off surface?

\subsection{Dataset and Provenance}
\label{subsec:data}

We evaluate on an open, provenance-traced benchmark built from public university course artifacts and labor-market taxonomies spanning {\NumUniversities} universities across {\NumCountries} countries (USA, Sweden, UK). The released benchmark contains {\NumPrimaryArtifacts} primary text artifacts ({\NumCourses} courses, {\NumPrograms} program outcome descriptors, {\NumOccupations} O*NET occupations, and a {\NumMissionsExpanded}-text mission corpus) and {\NumAttributeRecords} structured attribute/link records.

\paragraph{Stakeholder objectives.}
We report results in two evaluation modes:
(i) {ADS-Full} uses four stakeholder objectives implemented in the prototype (market, mission, university/curriculum, learner persona), and
(ii) {ADS-2D} uses an interpretable 2-objective slice (market+mission).
Market and mission objectives are instantiated by target corpora (job roles; mission texts). The university/curriculum and learner objectives use fixed target texts to make the evaluation reproducible; we treat real learner personalization and institutional policy specification as deployment-time inputs (Limitations).

\subsection{Experimental Setup}
We embed artifacts with sentence encoders from \texttt{sentence-transformers}~\cite{reimers2019sentencebert}: MiniLM (\texttt{all-MiniLM-L6-v2}, 384d) as primary encoder and MPNet (\texttt{all-mpnet-base-v2}, 768d) as ablation. A stub (random) encoder provides a sanity baseline. For each option or target corpus, we mean-pool artifact embeddings and L2-normalize before cosine scoring. Unless stated otherwise, we use identity lenses and $\tau{=}0.25$.

\subsection{Baselines and Metrics}
We compare \MAPE to two families of baselines: (i) \emph{scalarization} methods---weighted-sum maximization over a weight grid, random scalarization (sampling weight vectors), and lexicographic orderings; and (ii) \emph{$\varepsilon$-constraint} methods that optimize a single primary objective subject to minimum thresholds on the others~\cite{miettinen1999nonlinearMOO}.

We report: feasible Pareto size $|\mathcal{P}_\tau|$, \emph{hypervolume} (HV) of the selected set (volume of objective space dominated; higher means better coverage and quality~\cite{zitzler1999hv}), \emph{spacing} (mean nearest-neighbor distance among selected solutions; lower means more uniform distribution of trade-offs), set overlap (Jaccard), and runtime scaling. All HV values use reference point $r = 0$ in $\mathbb{R}^m$. After z-score calibration, $r = 0$ corresponds to the per-objective mean, ensuring all above-average Pareto options contribute positively to hypervolume; for $m > 2$ objectives, HV is approximated via Monte Carlo integration ($10{,}000$ samples, seed$=$42). For $\varepsilon$-constraint, we run three variants, each maximizing one of market/mission/learner with the remaining objectives constrained at their median values.

\paragraph{Why Pareto over other MOO methods?}
All baselines require implicit value commitments: scalarization requires weights, lexicographic ordering requires a priority hierarchy, and $\varepsilon$-constraint requires choosing a primary objective and threshold levels~\cite{roijers2013survey_mosdm}. \MAPE instead surfaces the \emph{full feasible Pareto set}, deferring value judgements to human decision-makers. The $\tau$ constraint filters extreme options but does not rank the remaining frontier.

We do not compare to Course2Vec-style recommenders~\cite{morsy2019course2vec} because \MAPE evaluates multi-stakeholder trade-offs, not preference prediction; it could serve as a re-ranking stage atop traditional recommenders.

\subsection{Key Results}

\paragraph{Pareto achieves the best hypervolume and selects different options than baselines.}
In ADS-Full (4-objective evaluation), \MAPE returns a {\MainParetoSize}-item \emph{feasible} Pareto set at $\tau{=}0.25$ with the highest hypervolume (HV$=${\MainHypervolume}). Even the best baseline (random scalarization, HV ratio$=${\BestBaselineHVRatio}) selects substantially different options: Jaccard overlap is only {\BestBaselineJaccard} (Fig.~\ref{fig:scalarization}). All scalarization methods embed implicit value commitments that bias selection; \MAPE surfaces the complete trade-off surface without pre-committing to weights or priorities.

\paragraph{$\varepsilon$-constraint and lexicographic methods miss the balanced frontier.}
$\varepsilon$-constraint baselines (optimize one objective subject to median thresholds on others) and lexicographic methods achieve HV ratios of 0.67--0.85 (Table~\ref{tab:baselines} in the appendix). These methods require \emph{choosing} a primary objective a priori, which biases selection: $\varepsilon$-constraint (market) and lexicographic (market) share only 28 of 141 options with the Pareto set (Jaccard$=$0.11). \MAPE exposes the full multi-stakeholder frontier without pre-committing to a single objective.

\paragraph{The market--mission slice reveals qualitatively distinct trade-offs.}
The 2D projection (Fig.~\ref{fig:scatter2d}) shows the Pareto frontier spans from max-market options through balanced options to max-mission options. These are not near-duplicates---they represent qualitatively different curricular philosophies that scalarization would collapse.

\paragraph{Concrete example.}
MIT's ``Machine Learning'' (6.867) and KTH's ``Sustainable Development'' (MJ1501) are both Pareto-optimal with complementary profiles across three of the four objectives: 6.867 dominates on market (0.72 vs 0.28), while MJ1501 leads on mission (0.68 vs 0.31) and learner (0.71 vs 0.45). Equal-weight scalarization would rank MJ1501 higher, concealing \emph{which} stakeholder drove the result. \MAPE instead presents both with full 4-objective score vectors and retrieval-grounded explanations.

\paragraph{Extrinsic validation.}
Three automated proxy checks confirm that Pareto scores reflect meaningful structure: (i) Pareto courses form a compact frontier (37\% lower pairwise distance than random, $p < 0.001$) yet span all 4 objectives (Shannon $H = 0.58$ vs.\ 0.27, $p < 0.001$); (ii) market scores correlate with O*NET occupation match ($\rho = 0.571$, $p \approx 0$; top-quartile 47.6\% higher match than bottom). NSGA-II~\cite{deb2002nsga2} comparison validates that exhaustive enumeration is exact and 33$\times$ faster for finite catalogues (Appendix~\ref{sec:supp-results}).

\paragraph{Real-data grounding of learner and curriculum objectives.}
To verify that the Pareto front is not an artifact of synthetic target construction, we replace fixed learner/curriculum targets with real-data-grounded alternatives: learner personas are centroids of related O*NET occupation embeddings (5 personas, 7--45 source occupations each), and curriculum targets are per-university course centroids or College Scorecard program descriptors (8 configurations). Across 40 real-target configurations, mean HV = 0.092 $\pm$ 0.017 (10.2$\times$ the synthetic baseline), consistent with meaningful semantic structure in the educational option space (Appendix~\ref{sec:supp-real-grounding}).


\section{Limitations, Ethics, and Reproducibility}
\label{sec:ethics}

\paragraph{Limitations.}
\ADS inherits limitations of embedding-based representations: scores depend on corpus coverage, suffer under domain shift, and can reflect representational bias~\cite{reimers2019sentencebert}. More fundamentally, lenses and target corpora encode value judgements. If we mis-specify them, the resulting trade-off surface can be misleading even if the optimization is correct. In this paper we evaluate option-level pathways; multi-step planning adds prerequisite constraints and compounds error across steps. Our pilot results indicate that the framework increases rather than reduces cognitive load (mean 3.38/5), a limitation of the current interface design.

\paragraph{Dataset limitations.}
The benchmark has geographic and linguistic bias: 68\% of courses are from US universities, and all text is English. O*NET reflects US labor market structure; transferability to other economies is untested. Course descriptions vary in quality and completeness across sources. Mission statements are institution-level, not program-specific. Temporal coverage is a snapshot (2024--2025); curriculum and labor markets evolve. We mitigate some limitations through provenance tracking and release multiple O*NET versions for drift analysis.

We report a preliminary practitioner pilot ($n{=}13$) providing directional support for trade-off transparency and perceived usefulness, but this is not evidence of improved learner outcomes. Establishing causal impact (e.g., retention, completion, downstream employment) requires longitudinal deployment and remains future work.

\paragraph{Ethical considerations.}
We use public/open artifacts and avoid personally identifiable information (PII). A key risk is over-optimizing for market alignment at the expense of learner autonomy or mission commitments~\cite{ekstrand2019fairness}. \MAPE addresses this by (i) making objectives explicit and inspectable, (ii) exposing trade-offs via Pareto sets, and (iii) enforcing a tunable dominance constraint. Nevertheless, any deployment should include human oversight and mechanisms for contestation~\cite{alfrink2023contestable,dignum2025contesting}.

\paragraph{Failure modes.}
Important failure modes include: (i) \emph{embedding bias} or domain shift that changes similarity scores; (ii) \emph{target mis-specification} (e.g., incomplete or biased market/mission corpora); (iii) \emph{objective gaming} where users optimize for a visible objective at the expense of latent goals; and (iv) \emph{single-objective dominance} where one objective is treated as the ``true'' goal.

Because target corpora are explicit inputs, they are also a potential misuse surface: a malicious or careless actor could manipulate outputs by substituting, poisoning, or cherry-picking the target corpora. \ADS/\MAPE mitigates these risks by making objectives and targets explicit (auditable corpora + lenses), returning a \emph{set} of trade-off options rather than a single ranking, and logging provenance so that disputed outputs can be traced to a concrete dataset snapshot. The dominance threshold $\tau$ is an evaluation parameter that should be set with domain input, not treated as a purely technical hyperparameter.

\paragraph{Reproducibility.}
We provide deterministic experiment scripts with fixed random seeds (0, 1, 2), dataset manifests with content hashes, and generated paper artifacts (figures/tables). The full dataset and code will be released upon acceptance.


\section{Conclusion}

We presented \ADS, a cross-national educational benchmark for multi-objective pathway evaluation spanning {\NumUniversities} universities across {\NumCountries} countries. We defined three benchmark tasks with standardized metrics and provided \MAPE as a reference baseline.

\paragraph{Key findings.}
The benchmark reveals a rich trade-off structure. First, Pareto evaluation returns the complete feasible set ({\MainParetoSize} options at default $\tau$), achieving the highest hypervolume; even the best baseline selects substantially different options (Jaccard$=${\BestBaselineJaccard}). Second, the dominance threshold $\tau$ provides meaningful control, filtering extreme options while preserving frontier diversity. Third, cross-national analysis reveals objective profile differences consistent with known curricular emphases: international universities lead on learner-centered objectives (+{\LearnerGapPercent}), US universities on market alignment. Each university contributes unique Pareto-optimal courses with complementary objective profiles---cross-institutional and cross-national diversity is essential for this benchmark.

\paragraph{For the community.}
For researchers, we release an open benchmark with standardized evaluation tasks and a reference baseline, lowering the barrier to entry for multi-objective educational evaluation. For practitioners, \MAPE offers a decision map rather than a single ranking, making trade-offs explicit.

\paragraph{Limitations and future work.}
Embedding similarity is not ground truth; corpora encode value judgements; and we have not measured downstream learner outcomes. A preliminary pilot ($n{=}13$) provides directional evidence that making trade-offs explicit is perceived as useful, but causal claims require longitudinal deployment. Future work includes interactive drill-down interfaces, integration with operational constraints, and outcome studies.

This will test whether Pareto-based trade-off presentation improves interpretability, contestability, and defensibility of curriculum decisions under realistic time constraints.

\paragraph{Participants.} 5 - 10 practitioners involved in course design (instructional designers, course creators, and/or program leads). Recruitment will be via the partner network; participation will be voluntary.

\paragraph{Stimuli.} 3 - 4 course-design scenarios. For each scenario we generate: (i) a Pareto set with 5 - 8 highlighted feasible options plus retrieval-grounded explanations, and (ii) a baseline ranked list produced by weighted-sum scalarization using the same objectives.

\paragraph{Conditions.} Within-subject comparison between:
(A) {Ranked list (scalarization)} and
(B) {Pareto set + dominance guardrail} (\MAPE with the default $\tau$).
Order will be counterbalanced across participants and scenarios.

\paragraph{Outcome measures.} We will collect:
(i) selection time; (ii) self-reported confidence and perceived autonomy; (iii) perceived usefulness/interpretability/actionability; (iv) ability to articulate trade-offs (coded from short written justifications); and (v) qualitative feedback on missing signals (uncertainty, constraints, evidence).

\paragraph{Procedure.} For each scenario, participants review the output, choose an option, and provide a brief rationale. Semi-structured follow-up questions probe interpretability, governance value (e.g., setting/justifying $\tau$), and desired ``control knobs'' (design moves that shift a solution along objectives).

\paragraph{Ethics and reporting.} Participation will be based on informed consent; quotations will be anonymized; no sensitive personal data will be collected. Results will be reported as descriptive statistics plus a thematic synthesis.

\paragraph{Interview guide (question prompts).} The semi-structured guide used in the interviews and pilot includes prompts on: first reaction; comparison to current practice; interpreting trade-offs; choosing and justifying an option; missing information (uncertainty, constraints, recourse); who would use the tool; governance guardrails (dominance threshold); social impact; and suggested improvements.

\section{\MAPE method details}
\label{sec:supp-method-details}

This section provides the full formalism for the \MAPE reference baseline summarized in Section~\ref{sec:method}.

\paragraph{Embedding.}
A pretrained sentence encoder $r:\mathcal{T}\to\mathbb{R}^d$ maps each text artifact (course description, occupation profile, mission statement) to a dense vector. We use MiniLM (384-dim) by default with MPNet (768-dim) for ablation. Embeddings are L2-normalized before scoring.

\paragraph{Stakeholder-specific scoring.}
For each stakeholder $a\in\mathcal{A}$, let $T_a=\{t_1^a,\dots,t_{n_a}^a\}$ denote the target corpus (e.g., O*NET occupations for market, mission statements for mission). The target centroid is $\mu_a = \frac{1}{n_a}\sum_{j} r(t_j^a)$, and the per-option score is:
\begin{equation}
  s_a(x) = \cos\bigl(L_a(r(x)),\; L_a(\mu_a)\bigr),
\end{equation}
where $L_a:\mathbb{R}^d\to\mathbb{R}^d$ is a stakeholder-specific \emph{lens} (see Section~\ref{sec:supp-lenses} below).

\paragraph{Z-score calibration.}
Raw cosine scores have different distributions across stakeholders. We standardize:
\begin{equation}
  \tilde{s}_a(x) = \frac{s_a(x) - \bar{s}_a}{\sigma_a}, \qquad
  \bar{s}_a = \frac{1}{|\mathcal{X}|}\sum_{x\in\mathcal{X}} s_a(x).
\end{equation}
All subsequent operations (dominance, Pareto computation, HV) use z-scored values.

\paragraph{Dominance gap and feasibility.}
The balanced dominance gap measures the worst-case score imbalance:
\begin{equation}
  g(x) = \max_{a,b\in\mathcal{A}} \bigl(\tilde{s}_a(x) - \tilde{s}_b(x)\bigr).
\end{equation}
The feasible set is $\mathcal{X}_\tau = \{x\in\mathcal{X} : g(x)\le\tau\}$.

\paragraph{Pareto computation.}
We compute the exact Pareto front via pairwise dominance over z-scored objective vectors:
$x$ dominates $y$ iff $\tilde{s}_a(x)\ge\tilde{s}_a(y)$ for all $a$ and $\tilde{s}_a(x)>\tilde{s}_a(y)$ for at least one $a$. The feasible Pareto set is:
\begin{equation}
  \mathcal{P}_\tau = \{x\in\mathcal{X}_\tau : \nexists\, y\in\mathcal{X}_\tau \text{ s.t.\ } \mathbf{\tilde{s}}(y)\succ\mathbf{\tilde{s}}(x)\}.
\end{equation}
Exhaustive enumeration is exact and tractable for finite catalogues ($\mathcal{O}(n^2 m)$ for $n$ options, $m$ objectives); NSGA-II comparison confirms this is faster and provably optimal (Table~\ref{tab:nsga2}).

\paragraph{Retrieval-grounded explanations.}
For each Pareto-optimal $x$ and each stakeholder $a$, \MAPE returns:
(i)~the z-scored objective vector $\tilde{\mathbf{s}}(x)$,
(ii)~the dominance gap $g(x)$,
(iii)~the $k$ nearest target artifacts $\mathrm{argmax}_{t\in T_a} \cos(r(x), r(t))$ as evidence, and
(iv)~a stakeholder-typed label (``market-strong'', ``mission-aligned'', etc.) derived from score ranks.

\paragraph{Algorithm summary.}
\begin{enumerate}
  \item Embed all options $\mathcal{X}$ and all target corpora $\{T_a\}$ with encoder $r$.
  \item Compute per-stakeholder scores $s_a(x)$ for all $x\in\mathcal{X}$, $a\in\mathcal{A}$.
  \item Z-score calibrate: $\tilde{s}_a(x)$.
  \item Filter by dominance gap: $\mathcal{X}_\tau$.
  \item Compute exact Pareto front: $\mathcal{P}_\tau$.
  \item Generate retrieval-grounded explanations for each $x\in\mathcal{P}_\tau$.
\end{enumerate}

Steps 1--2 dominate runtime (embedding is cached); steps 3--6 complete in $<$1s for 33K options. Total wall-clock: {\MainRuntimeSec}s with cached embeddings.


\section{Lens variants}
\label{sec:supp-lenses}
\subsection{Identity and diagonal lenses}
In the prototype, a lens $L_a:\mathbb{R}^d\to\mathbb{R}^d$ is a linear reweighting of embedding dimensions.
The identity lens is $L_a(v)=v$.
A diagonal lens is $L_a(v)=\mathrm{diag}(\ell_a)\,v$, where $\ell_a\in\mathbb{R}_{\ge 0}^d$.
Diagonal lenses are easy to audit and can be interpreted as feature importances over embedding dimensions.

\subsection{Learned diagonal lenses (prototype)}
The learned diagonal lens emphasizes dimensions predictive of whether a text belongs to a stakeholder corpus.
A lightweight implementation trains a one-vs-rest logistic regression classifier on embeddings to separate stakeholder target texts from background texts.
Let $w_a\in\mathbb{R}^d$ denote the learned weight vector. We form a nonnegative diagonal weight vector by $\ell_a = |w_a|$ (or a clipped/normalized variant), and set $L_a(v)=\mathrm{diag}(\ell_a)\,v$.
{Note:} this is an interpretable lens; richer lens learning (e.g., low-rank or neural transforms) is possible but not required for the ADS formalism.

\section{Pathway (sequence) scoring variants}
The main paper focuses on option-level evaluation ($T=1$). For multi-step pathways $\pi=(x_1,\dots,x_T)$, the prototype supports several aggregation choices:
\begin{itemize}
  \item {Profile aggregation:} form $v_\pi = \frac{1}{T}\sum_{t=1}^T v_{x_t}$ and compute $s_a(\pi)=\cos(L_a(v_\pi),L_a(\mu_a))$.
  \item {Score aggregation:} compute per-step scores $s_a(x_t)$ and aggregate $s_a(\pi)=\sum_t w_t s_a(x_t)$ with optional discounting.
  \item {Constraint-aware aggregation:} require feasibility at each step (or constrain cumulative dominance gap).
\end{itemize}
These variants separate representation effects (embedding + lenses) from planning effects (search under prerequisites).

\section{Dominance / autonomy-drift constraints}
The main paper uses a dominance-gap constraint $g(x)=s_{\text{market}}(x)-\max_{b\ne \text{market}} s_b(x)$.
Alternative constraints that can be substituted without changing the rest of the pipeline include:
\begin{itemize}
  \item {Max-gap across all stakeholders:} $g(x)=\max_{a,b}(s_a(x)-s_b(x))$.
  \item {Market-vs-others average:} $g(x)=s_{\text{market}}(x)-\frac{1}{m-1}\sum_{a\ne \text{market}} s_a(x)$.
  \item {Weighted dominance:} $g(x)=s_{\text{market}}(x)-\sum_{a\ne \text{market}} \lambda_a s_a(x)$ with governance weights $\lambda_a$.
\end{itemize}

\section{Stability metrics and perturbations}
\label{sec:supp-stability}
\subsection{Set overlap}
Given two Pareto sets $\mathcal{P}$ and $\mathcal{P}'$, we measure overlap with the Jaccard index
\begin{equation}
  J(\mathcal{P},\mathcal{P}') = \frac{|\mathcal{P}\cap\mathcal{P}'|}{|\mathcal{P}\cup\mathcal{P}'|}.
\end{equation}

\subsection{Perturbation procedures}
We apply three perturbation families:
(i) {embedding/score noise:} add small isotropic noise before normalization;
(ii) {target perturbation:} resample a fraction of the target corpus and recompute $\mu_a$;
(iii) {lens noise:} perturb diagonal weights $\ell_a$ by multiplicative noise.

\subsection{Bootstrap robust Pareto core}
To quantify which Pareto members are stable versus boundary-sensitive, we run $B = 100$ bootstrap rounds with Gaussian noise $\varepsilon \sim \mathcal{N}(0, 0.01^2)$ added to every $z$-scored coordinate. For each round we recompute the Pareto front and count per-course membership frequency $f_i$.

\textit{Note:} The bootstrap analysis uses the unconstrained Pareto set (without $\tau$ filter) to measure inherent frontier stability; the main-text results apply $\tau = 0.25$. This explains the larger base sizes here (169 MiniLM, 79 MPNet) compared to the $\tau$-filtered main results ({\MainParetoSize} MiniLM, {\MPNetParetoSize} MPNet).

\paragraph{MiniLM encoder.} The unperturbed Pareto set contains 169 courses (mean perturbed size 120, mean Jaccard with base $= 0.661$). The robust core ($f_i > 0.90$): 80 courses retaining $>$99.9\% of hypervolume. At $f_i > 0.50$: 98 courses with 100\% HV retention.

\paragraph{MPNet encoder.} More stable: base front 79 courses, mean Jaccard $= 0.895$, robust core ($f_i > 0.90$): 61 courses retaining 98.0\% of HV.

\paragraph{Encoder-ensemble core.} Intersecting both $>$90\% cores yields 10 courses spanning 6/7 universities (MIT, UC Berkeley, Stanford, Cornell, KTH, Edinburgh). These represent the most robustly optimal trade-offs across both perturbation \emph{and} encoder choice. The low Jaccard previously reported (0.068 at $\varepsilon = 0.01$) reflects boundary churn, not instability of the actionable core.

\subsection{Extrinsic validation details}
Three automated proxy checks validate that Pareto scores reflect educational and labor-market structure:

\paragraph{Pareto-frontier compactness.} Pareto-optimal courses form a compact efficient frontier in the 4D objective space: 37\% lower mean pairwise Euclidean distance and 84\% smaller bounding-box volume than 1,000 random samples of equal size ($p < 0.001$, Cohen's $|d| = 8.6$).

\paragraph{Objective specialization.} Despite compactness, Pareto courses span all 4/4 stakeholder objectives with maximum single-objective concentration of 75\% and normalized Shannon entropy $H = 0.58$ (vs.\ 91\% concentration and $H = 0.27$ for random, $p < 0.001$). Per-objective breakdown: university=78, mission=12, learner=11, market=3.

\paragraph{Market--O*NET alignment.} Spearman $\rho = 0.571$ ($p \approx 0$) between market score and best-match O*NET occupation similarity. Top-quartile courses: mean best-match $= 0.505$; bottom-quartile: $0.342$ (+47.6\% gap), with monotonic decrease across all four quartiles. This indicates market scores capture occupational structure.

\paragraph{Expert annotation protocol (future work).} We propose a structured annotation study: 3--5 domain experts (curriculum designers, career counselors) independently rate 50 Pareto-optimal and 50 randomly selected non-Pareto courses on three 5-point Likert scales (overall quality, perceived stakeholder trade-off clarity, real-world alignment) in a blinded, randomized design. Inter-rater reliability (Krippendorff's $\alpha$) and mean rating differences provide human-grounded validation. The benchmark releases annotation templates for community adoption.

\section{Task-agnostic benchmark protocol}
\label{sec:supp-benchmark-protocol}

\paragraph{Motivation.}
A benchmark coupled to a single formalism limits external participation and reproducibility.
We decouple the evaluation from \ADS by specifying three tasks purely in terms of observable inputs (course text artifacts, stakeholder target corpora) and outputs (ranked course IDs with optional per-course score vectors).
Any method---embedding-based, feature-engineered, or LLM-based---can produce a conforming submission without importing ADS code.

\paragraph{Task A: Multi-Stakeholder Course Ranking.}
\textit{Input:} Course text corpus $\mathcal{C}$, stakeholder target corpora $\{T_k\}_{k=1}^{m}$.
\textit{Output:} Ordered list of course IDs with optional per-course score vectors.
\textit{Metrics:} Coverage (fraction of objective-space grid cells occupied), diversity (mean pairwise distance), objective balance (normalized Shannon entropy), external alignment (precision, recall, F1, Jaccard against reference Pareto set).

\paragraph{Task B: Stakeholder Trade-off Discovery.}
\textit{Input:} Same as Task~A.
\textit{Output:} Set of course IDs representing distinct stakeholder trade-offs.
\textit{Metrics:} Hypervolume (HV, $\mathbf{r} = \mathbf{0}$), spacing (mean nearest-neighbor distance; lower = more uniform), spread (bounding-box volume), Pareto precision (fraction on true front), dominance resistance (fraction non-dominated within submission).

\paragraph{Task C: Robust Recommendation.}
\textit{Input:} Same as Task~A, plus perturbation protocol ($\sigma$, weight jitter).
\textit{Output:} Primary submission plus $\geq 2$ perturbation-run submissions.
\textit{Metrics:} Bootstrap Jaccard, HV retention ($\min/\max$), rank stability (Spearman), core stable fraction ($\geq 80\%$ of runs).

\paragraph{Submission format.}
Submissions are JSON files with fields: \texttt{method\_name}, \texttt{task} (A/B/C/all), \texttt{ranked\_courses} (list of IDs), \texttt{scores} (optional dict of ID $\to$ objective vector), and \texttt{perturbation\_runs} (required for Task~C).
The evaluation script (\texttt{benchmark\_eval.py}) depends only on NumPy and the Python standard library.

\paragraph{External baseline results.}

\section{Extended related work map}
\label{sec:rw-extended}

This section provides an expanded map of related work for Agent--Didactic Spaces (ADS).
The main paper includes a compact related-work section; here we add more context to help reviewers assess where ADS sits relative to existing literature.
We organize the works into six groups: (i) LLM-based educational assistants and agentic tutoring, (ii) educational recommender systems and learning paths, (iii) student modelling and knowledge tracing, (iv) multi-stakeholder recommendation and fairness-aware evaluation, (v) multi-objective optimization and multi-objective RL, and (vi) contestable AI and counterfactual recourse.

\subsection{LLM-based educational assistants and agentic tutoring}
\label{sec:rw-llm-edu}

Recent surveys describe the rapidly expanding design space for large language models (LLMs) in education \cite{wang2024llmedu,chu2024llmeduSurvey} and discuss their role in ``Education 4.0'' settings \cite{caccavale2024education4}.
In parallel, there is active work on pedagogically grounded evaluation criteria and taxonomies for AI-based tutors and educational agents \cite{maurya2025taxonomy,maurya2025pedagogy}.
These lines of work are complementary to ADS: they primarily study \emph{interaction-time} tutoring quality and learning outcomes, whereas ADS targets \emph{pre-deployment} evaluation and governance of candidate educational pathways/resources under multiple stakeholder objectives.

A representative set of agentic education systems includes:
\begin{itemize}
    \item {Student simulation and personalized tutoring.} \emph{CoderAgent} simulates student behaviour to support personalized programming instruction \cite{coderagent2025}.
    \item {Multi-agent pedagogical interaction.} LLM-based collaborative agents with pedagogy-guided interaction modelling have been explored for educational dialogue and group learning settings \cite{collabAgents2025}.
    \item {Teachable agents and debugging tutors.} Teachable-agent paradigms for teaching programming in the LLM era \cite{teachProg2025} and LLM-based tutoring for hypothesis construction in debugging \cite{ma2023hypocompass} focus on interactive instruction and formative feedback.
    \item {Assessment and feedback.} LLM-powered automated grading \cite{llmGrading2025} and multimodal tutoring with structured feedback \cite{handByHand2025} demonstrate how LLMs can support assessment and practice.
    \item {Domain-specific learning experiences.} \emph{LivePoem} illustrates LLM-based support in culturally specific domains (e.g., classical Chinese poetry) \cite{livepoem2025}.
    \item {Goal-oriented tutoring pipelines.} \emph{GenMentor} proposes a goal-oriented, skill-mapping tutoring pipeline built around an LLM-powered multi-agent framework \cite{wang2025genmentor}.
    \item {Classroom-level simulation.} \emph{SimClass} explores simulating classroom teaching/learning dynamics with LLM-empowered agents \cite{zhang2024simclass}.
    \item {Collaborative multimodal student support.} \emph{MultiTutor} studies collaborative LLM agents for multimodal student support \cite{sun2025multitutor}.
\end{itemize}

\noindent
These systems generate candidate recommendations but leave implicit how stakeholder trade-offs are resolved. ADS provides an evaluation layer that can score such candidates across explicit objectives with auditable lenses.

\subsection{Educational recommender systems and learning paths}
\label{sec:rw-ers}

Educational recommender systems (ERS) have a long history of recommending courses, resources, and learning pathways, with surveys highlighting both promise and recurring limitations \cite{shi2020,dasilva2022slrERS,aucancela2023ersslr}.
A key challenge is that pathway decisions are rarely single-objective: practical deployments must balance learner-centric objectives with institutional and regulatory constraints, and with external signals such as employability.

Within ERS, several directions connect directly to how ADS constructs and evaluates candidate pathways:
\begin{itemize}
    \item {Course representation and semantic modelling.} Course embedding approaches study how to represent course content and transaction data for downstream recommendation \cite{jiang2020multifactorCourse2vec,xu2023courseEmbeddings}.
    \item {Sequence/trajectory recommendation.} Recent models use hierarchical reinforcement learning and structured prerequisite representations to recommend course sequences \cite{hhcor2024} and exploit feedback signals to refine resource recommendations \cite{dfrp2024}.
    \item {Outcome-aware optimization.} Online Bayesian educational recommenders aim to optimize learning outcomes under uncertainty \cite{ober2025}.
    \item {Systems-level and agent-based perspectives.} Viewing education as a complex system via computational and agent-based modelling \cite{vulic2024complexEdu,reardon2016abm-education} motivates explicit multi-actor modeling of goals and incentives.
    \item {Curriculum design constraints.} Engineering education frameworks such as CDIO \cite{crawley2011cdio} and NEET-style reform efforts \cite{crawley2018neet} highlight that curricula are governed by institutional missions and constraints beyond individual preference.
\end{itemize}

\noindent
ADS is agnostic to the upstream ERS algorithm; it evaluates candidate pathways under multiple objectives and reports trade-offs as a Pareto set rather than a single score, complementing any of the above approaches.

\subsection{Student modelling and knowledge tracing}
\label{sec:rw-kt}

A large body of work in educational data mining focuses on modelling learner knowledge state, predicting performance, and providing interpretable signals for intervention.
Recent IJCAI contributions illustrate several relevant advances:
\begin{itemize}
    \item {Explainable knowledge tracing.} Priority-guided explanations for knowledge tracing aim to provide more faithful rationales for predicted mastery \cite{li2025pgexplainkt}.
    \item {Transfer across courses.} Cross-course knowledge transfer with concept-graph guidance addresses transfer and cold-start issues in knowledge tracing \cite{han2025transkt}.
    \item {Representation denoising.} Denoised attention and question-augmented representations improve robustness of attention-based knowledge tracing \cite{deng2025denoisekt}.
    \item {Length generalization.} Linear-bias mechanisms to enhance length generalization in attention-based knowledge tracing \cite{li2024stablekt} address practical deployment where sequences vary.
    \item {Forgetting and time.} Continuous time-aware neural approaches reconcile cognitive modelling with knowledge forgetting \cite{ma2022ctncm}.
    \item {Action selection under multi-skill tasks.} Fast action selection formulations combine skill modelling with sequential decision-making \cite{salomons2021bktpomdp}.
    \item {Performance prediction.} Graph and hypergraph-based contrastive learning approaches predict student performance from structured educational interactions \cite{song2025mhmgcl}.
\end{itemize}

\noindent
Predicted mastery, dropout risk, or sequence-length robustness from these models could serve as additional ADS objectives or lens features, but ADS deliberately separates multi-stakeholder evaluation from the choice of learner-state model.

\subsection{Multi-stakeholder recommendation and fairness-aware evaluation}
\label{sec:rw-ms}

Multi-stakeholder recommendation explicitly models the preferences and utilities of multiple parties.
Surveys and evaluation frameworks highlight that multi-stakeholder settings require evaluation beyond standard user-centric metrics \cite{abdollahpouri2020multistakeholder,burke2025mseval} and are increasingly discussed under the broader umbrella of trustworthy recommender systems \cite{ge2024trustworthyRS}.
Explainable recommendation surveys further stress the need for transparency and user understanding in recommendation pipelines \cite{zhang2020explainableRS}.

Fairness and discrimination issues are central in high-stakes recommendation and retrieval, including tutorial-style syntheses for the recsys community \cite{ekstrand2019fairness}.
Formal fairness notions such as fairness through awareness \cite{dwork2012fairness} and equality of opportunity \cite{hardt2016equality} motivate explicit constraint handling and audits.
The cost-of-fairness framework formalizes accuracy--equity trade-offs in algorithmic decisions~\cite{corbettdavies2017cost}; pairwise fairness in recommendation ranking~\cite{beutel2019fairness} and fair-division approaches to ranked output~\cite{saito2022fair} provide practical mechanisms.
In education-specific contexts, work on fairness stability in disentangling educational inequality highlights temporal and structural pitfalls \cite{fairdas2024}.
Rank aggregation under fairness constraints provides algorithmic tools for combining stakeholder views \cite{fairRankAgg2025}.
Preference-based fairness certification \cite{prefFairCert2023} and learning-when-to-advise setups \cite{advise2023} motivate evaluation protocols that account for downstream human decision-makers.

Several domains illustrate why multi-stakeholder and fairness-aware evaluation matters:
\begin{itemize}
    \item {Job and skill recommendation.} Skills-aware job recommendation and skill extraction/representation methods \cite{giabelli2021skills2job,kara2022skillEmbeddings,leon2024transversalSkills} provide concrete examples of labour-market alignment pipelines. Market-aware skill extraction at scale~\cite{shi2020job2skills} and career-path modelling via hierarchical neural networks~\cite{meng2019career} further demonstrate the richness of labour-market signal.
    \item {Fairness in job recommendation.} ``Job recommendation for all'' highlights inequity risks and mitigation in employment-facing recommenders \cite{bied2023jobrecforall}. Adapting recommendations to user preference drift~\cite{han2024bistro} illustrates temporal challenges in employment-facing systems.
    \item {Democracy and robustness.} Robustness of recommendation-like systems in voting advice applications highlights adversarial concerns in civic contexts \cite{berdoz2025democracy}.
\end{itemize}

\noindent
ADS instantiates multi-stakeholder evaluation by making corpora and constraints first-class objects. The autonomy threshold $\tau$ encodes policy-level limits on how far recommendations may deviate from a learner's own goals, connecting directly to the fairness-aware mechanisms above.

\subsection{Multi-objective optimization and multi-objective RL}
\label{sec:rw-moo}

ADS relies on multi-objective reasoning to avoid collapsing educational pathway evaluation into a single scalar score.
Foundational discussions of multi-objective sequential decision-making \cite{roijers2013survey_mosdm} and algorithmic tools for faster Pareto-coverage computations \cite{roijers2015convex} motivate representing the output as a \emph{set} of trade-off solutions.
Classical evolutionary approaches such as NSGA-II \cite{deb2002nsga2} and standard references on nonlinear multi-objective optimization \cite{miettinen1999nonlinearMOO} provide algorithmic background; a KDD tutorial surveys multi-objective formulations specifically for recommendation systems~\cite{zheng2021multiobjective}.

Recent work continues to expand the toolset:
\begin{itemize}
    \item {Bandit-based Pareto discovery.} Multi-objective neural bandits explore efficient Pareto-front approximation under uncertainty \cite{monb2025}.
    \item {Equity as a multi-agent, multi-objective problem.} Equity-aware formulations in multi-agent multi-objective RL illustrate how welfare and distributional concerns can be encoded as objectives \cite{equityMAMORL2025}.
    \item {Normative constraints.} ``Restraining bolts''-style normative constraints in MORL motivate explicit governance parameters for acceptable behaviour \cite{restrainingBolts2025}.
    \item {Normative multi-agent alignment via evolutionary strategies.} Multi-objective evolutionary strategies for normative multi-agent systems provide another example of multi-value alignment under constraints \cite{riad2025nova}.
\end{itemize}

\noindent
ADS builds on this MOO toolbox by combining Pareto-set computation with education-specific stakeholder modelling and the $\tau$-bounded feasibility constraint.

\subsection{Contestable AI, counterfactual explanations, and recourse}
\label{sec:rw-contestable}

ADS explicitly targets contestability: decisions should be challengeable by affected parties.
General frameworks for contestable and contesting AI decisions motivate this stance \cite{aler2020contestable,alfrink2023contestable,dignum2025contesting}.
Counterfactual explanations are one practical mechanism for contestability \cite{wachter2017counterfactual}, while algorithmic recourse formalizes actionable changes to obtain a desired outcome \cite{ustun2019recourse}.
Robust counterfactual methods address instability under perturbations \cite{robustx2025}.
For sequential decision-making, counterfactual strategies for MDPs illustrate how ``what-if'' reasoning extends to policies \cite{cfmdp2025}.
Finally, efficiency-focused methods such as policy-gradient-optimized explainers aim to make explanations computationally feasible \cite{pan2025fex}.

\noindent
Rather than changing an input to flip a single prediction, ADS exposes the full trade-off set under explicit constraints, making stakeholder disagreements visible and therefore contestable.

\paragraph{Summary.}
Across these areas, ADS can be viewed as a bridge between (a) education-specific recommenders and learner models, and (b) the broader literature on multi-objective evaluation, fairness, and contestable decision-making.
The unifying theme is to make stakeholder trade-offs explicit and auditable, rather than implicitly encoded in a single optimization target.
